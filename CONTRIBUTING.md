# Contributing

Thank you for your interest in contributing to this project. Below are the current status, planned features, and guidelines for submitting changes.

## Current Status

Currently, the project only supports one camo per weapon. The primary objective is to expand this system so that all weapons have dedicated camos, ensuring base weapons and their Pack-a-Punched versions do not share the same camo.

## Planned Features & Goals

Contributions aimed at the following features are prioritized:

1. **Weapon Coverage & Separation**
   * Assign unique camos to all available weapons.
   * Ensure upgraded weapon variants use distinct camos from their base models.

2. **Dvar Configuration**
   * Implement a Dvar system to let users configure and select which camo to equip.

3. **Dynamic Camo Switching**
   * A mechanism to change the equipped camo instantly in real time during gameplay.
   * A trigger to automatically swap or cycle camos whenever the player switches weapons.
